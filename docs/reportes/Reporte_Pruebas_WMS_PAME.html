2. Hallazgos en Capa de Integración (Fallas Detectadas)

La investigación técnica identificó dos puntos críticos que requieren atención en la configuración de las pruebas o el despliegue:

Fallo en Dead Letter Queue (DLQ):
El servicio procesar_jobs_pendientes en siesa_job_service.py ejecuta la lógica pero no retorna el valor de los procesados a la función llamadora.
Impacto: Los procesos de monitoreo reciben "None" y no pueden confirmar el éxito de la tarea.
Restricción de Acceso API (403 Forbidden):
Los endpoints de configuración de límites y gestión de tareas han sido endurecidos y ahora requieren rol de admin o jefe_almacen.
Impacto: Los tests fallan porque utilizan un usuario de prueba con rol operario.

3. Recomendaciones Técnicas

  • Ajuste de Retorno: Modificar app/services/siesa_job_service.py para incluir el return faltante.
  • Actualización de Suite de Pruebas: Elevar el rol del usuario en tests/conftest.py de 'operario' a 'admin' para permitir la validación de endpoints de gestión.
  • Limpieza de Logs: Atender las advertencias de SQLAlchemy y Flask para reducir el ruido en los reportes de integración continua.
